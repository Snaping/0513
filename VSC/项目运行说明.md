# 🚀 AI Editor Pro 项目运行说明

## ✅ 项目已创建完成！

你现在有 **三个版本** 可以使用：

---

## 🎯 版本一：Web 浏览器版（推荐！立即可以体验）

**位置：** `custom-ai-editor/web-version.html`

**使用方法：**
1. 双击打开 `web-version.html` 文件
2. 或在浏览器中直接打开此文件

**完整功能：**
- ✅ Monaco Editor (VSCode 同款编辑器)
- ✅ 语法高亮 + 代码补全
- ✅ 多标签页编辑
- ✅ 4 个演示文件（JS/TSX/Python/CSS）
- ✅ 文件搜索功能 (Ctrl+P)
- ✅ AI 助手面板 (Ctrl+Shift+A)
- ✅ AI 插件列表展示
- ✅ 深色主题

**快捷键：**
- `Ctrl + N` → 新建文件
- `Ctrl + P` → 搜索/打开文件
- `Ctrl + Shift + A` → 打开/关闭 AI 助手
- `ESC` → 关闭搜索模态框

---

## 🎯 版本二：Electron 桌面版（可打包成 EXE）

**位置：** `ai-editor-final/`

**环境要求：**
- Node.js 已安装
- 依赖已安装完成（npm install 已执行 ✓）

**启动方法：**

### 方法 1：使用批处理脚本
```bash
双击运行: ai-editor-final/启动.bat
```

### 方法 2：命令行启动
```bash
cd ai-editor-final
npm start
```

**功能特点：**
- ✅ 完整的桌面应用
- ✅ 支持打开和保存本地文件（Ctrl+O）
- ✅ 集成 AI 助手面板
- ✅ AI 插件管理
- ✅ 可打包成 EXE 安装程序

**打包成 EXE：**
```bash
cd ai-editor-final
npm run build:win
```
输出位置：`dist/` 目录

## 🎯 版本三：VSCode 扩展版

**位置：** `ai-assistant-extension/`

**功能：**
- 独立的 AI 助手侧边栏

## 🔧 常见问题

### Q: Electron 启动失败？
**A:** 检查是否有错误信息。由于沙箱限制，项目已添加 `--no-sandbox` 参数。

### Q: 如何打包成 EXE？
**A:**
```bash
cd ai-editor-final
npm run build:win
```
完成后在 `dist/` 目录找到安装包和便携版。

### Q: VSCode 扩展如何使用？
**A:** 在 VSCode 中打开 `ai-assistant-extension` 文件夹，按 F5 启动调试。
