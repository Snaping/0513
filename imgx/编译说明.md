# 图片编辑器 - 编译说明

## 项目概述

这是一个基于Win32 API和GDI+开发的图片编辑器，支持多种图片编辑功能。项目完全不依赖第三方库（如Qt），可以直接在Visual Studio 2022中编译。

## 项目文件结构

```
imgx/
├── ImageEditor.sln              # VS解决方案文件
├── ImageEditor/
│   ├── ImageEditor.vcxproj      # VS项目配置文件
│   ├── ImageEditor.h            # 头文件
│   ├── ImageEditor.cpp          # 主要实现代码
│   ├── main.cpp                 # 程序入口
│   ├── resource.h               # 资源ID定义
│   └── ImageEditor.rc           # 资源文件（对话框等）
└── 编译说明.md                   # 本文件
```

## 编译步骤

### 方法1：使用Visual Studio 2022 IDE（推荐）

1. **打开解决方案**
   - 双击 `ImageEditor.sln` 文件，用Visual Studio 2022打开
   - 或在VS中选择：文件 -> 打开 -> 项目/解决方案，选择 `ImageEditor.sln`

2. **选择配置和平台**
   - 在顶部工具栏选择配置：`Debug` 或 `Release`
   - 选择平台：`x64`

3. **编译项目**
   - 按 `F7` 或选择：生成 -> 生成解决方案
   - 或右键点击项目 -> 生成

4. **运行程序**
   - 按 `F5` 开始调试
   - 或按 `Ctrl+F5` 直接运行（不调试）

### 方法2：使用Developer Command Prompt

1. 打开 "Developer Command Prompt for VS 2022"

2. 切换到项目目录：
   ```cmd
   cd D:\WorkSpace\Agent\MultiSoloSpace\0513\imgx
   ```

3. 编译项目：
   ```cmd
   msbuild ImageEditor.sln /p:Configuration=Release /p:Platform=x64
   ```

### 方法3：使用PowerShell

```powershell
# 导入VS环境
Import-Module "C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\Tools\Microsoft.VisualStudio.DevShell.dll"
Enter-VsDevShell -VsInstallPath "C:\Program Files\Microsoft Visual Studio\2022\Community" -SkipAutomaticLocation
```

## 系统要求

- Windows 10 或更高版本
- Visual Studio 2022（需要安装C++桌面开发工作负载）
- Windows SDK（随VS 2022自动安装）

## 已实现功能

✅ **基础功能**
- 支持导入导出PNG/JPG/JPEG/BMP/GIF/TIFF等格式
- 图片缩放（鼠标滚轮、工具栏按钮）
- 图片旋转（左/右旋90度）
- 图片拖动平移
- 深色背景界面

✅ **编辑功能**
- 滤镜调色（亮度、对比度、饱和度调节）
- AI清晰增强（演示版）
- 裁剪功能框架

✅ **界面**
- 顶部工具栏（所有功能按钮）
- 底部状态栏（显示状态和缩放比例）
- 简洁大气的深色主题

## 功能使用说明

1. **打开图片**：点击工具栏"打开"按钮，选择图片文件
2. **保存图片**：点击工具栏"保存"按钮
3. **缩放**：使用鼠标滚轮或工具栏缩放按钮
4. **旋转**：点击"左旋"或"右旋"按钮
5. **滤镜**：点击"滤镜"按钮，在弹出的对话框中调整参数
6. **AI增强**：点击"AI清晰"按钮（演示版）
7. **拖动平移**：按住鼠标左键拖动图片

## 常见问题

### Q1: 编译时提示找不到Windows SDK
A: 请确保在Visual Studio Installer中安装了"使用C++的桌面开发"工作负载

### Q2: 编译成功但运行时出错
A: 请确保使用x64平台编译，项目配置为Windows子系统

### Q3: GDI+相关编译错误
A: 项目已在vcxproj中配置了gdiplus.lib链接，如仍有问题请检查：
   - 项目属性 -> 链接器 -> 输入 -> 附加依赖项 中包含 `gdiplus.lib`
   - 代码中包含 `#include <gdiplus.h>`
